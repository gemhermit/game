# 贝谷游戏 (Bago Game)

新一代游戏门户，汇聚精品在线游戏。

## 简介

贝谷游戏提供简洁、现代的在线游戏体验。本站基于 Material 3 设计规范构建，支持深色模式，适配各种设备屏幕。

## 游戏列表

- **4046**: 经典数字合成游戏
- **冲浪 (Surf)**: Edge 浏览器内置冲浪游戏移植版
- **地铁跑酷**: 经典的跑酷游戏
- **小恐龙 (Dino)**: Chrome 离线小恐龙游戏
- **云游戏**: 连接各大云游戏平台
- **动物枪王**: 趣味射击游戏

## 技术栈

- **HTML5 / CSS3**: 语义化标签与现代布局
- **BeerCSS**: 基于 Material Design 3 的轻量级 CSS 框架
- **Material Dynamic Colors**: 动态取色引擎

## 开发与部署

本项目为纯静态网站，可直接部署于任何静态网页托管服务（如 GitHub Pages, Vercel, Netlify 等）。

### 目录结构

- `index.html`: 首页入口
- `404.html`: 404 错误页
- `4096/`, `dino/`, `surf/`, `SubwaySurfers/`: 各个游戏的资源目录
